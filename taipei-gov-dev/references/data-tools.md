# 文件與資料處理工具

適用：處理 Excel、CSV、Word、PowerPoint、PDF 等檔案的工具，例如整理名單、合併多個檔案、批次套印公文或證書、從簡報或文件擷取文字、轉換格式、產生報表、批次改檔名。這類工具在承辦人電腦上執行，不需要網站的版面、Logo、頁尾規定。做成在瀏覽器打開的 HTML 工具時，畫面另依 SKILL.md 的 B 類辦理。

> 標記說明：〔法〕法律明文規定；〔府〕行政院或臺北市政府的指引、規定；〔建議〕本規範建議的做法。法規原文與來源見 `legal-sources.md`。

### 一、先保護資料，再寫程式

**先分清楚兩件事：**

| | AI 讀取資料 | 程式在本機處理資料 |
|---|---|---|
| 是什麼 | 你（AI）打開、預覽檔案，或看到程式執行時印出的內容 | 你寫好的程式，由承辦人在自己的電腦上執行，讀取真實檔案 |
| 資料去哪裡 | 送到 AI 服務 | 留在承辦人的電腦 |
| 真實資料可以嗎 | 含個資或未公開公務資訊時**不可以**（例外見下方） | **可以**，這正是這類工具的用途 |

所以：程式要讀取真實的 Excel、Word 是正常的，寫程式時照常讀取本機檔案；不可以的是讓真實資料的內容進到 AI。

1. **你不讀取真實檔案的內容。** 承辦人給的 Excel 常有民眾姓名、電話、身分證字號；Word、PowerPoint 常有簽稿、會議資料、尚未公開的政策內容。你讀取這些內容，就等於把資料送到 AI 服務，這違反行政院生成式 AI 參考指引第四點（不得提供應保密、個人及未經同意公開的資訊）與市府指引。〔府〕
   - Excel、CSV：請承辦人提供欄位名稱（第一列），以及 3 到 5 列**改成假資料**的範例。
   - Word、PowerPoint、PDF：請承辦人提供一份**內容換成假文字**、但保留原本版面與格式的範例檔，或用文字描述版面（例如「第一頁是標題，第二頁起每頁一個表格，表格有 4 欄」）。
   - 可以這樣說：「為了保護民眾資料和公務資訊，請不要把真實的檔案給我看。請另存一份把內容換成假資料的範例，格式保持不變，我照這個格式寫程式，您再用程式處理真實檔案。」
   - 承辦人已經把真實檔案放在資料夾裡時，不要開啟或預覽，包括工作表名稱與檔案摘要；檔名可能含個資，也不要列出。需要知道有幾個檔案、叫什麼名稱時，請承辦人告訴你，並另存一份範例版本。
   - 檔名、內容標示「密」「機密」，或明顯是機密文書時，依 soul.md 三（一）停止作業。製作機密文書禁止使用生成式 AI。〔府〕
2. **處理真實資料的程式，由承辦人自己執行。** 你只用假資料執行和測試。如果由你（AI 工具）執行程式去處理真實檔案，程式印出的訊息、錯誤訊息裡的資料，都會被你看到，等於又把資料送進 AI。交付時寫清楚承辦人要怎麼自己執行。〔府〕
3. **程式處理真實資料時的條件**：在承辦人自己的公務電腦，或機關核准的環境中執行；資料不上傳到任何外部服務；輸出檔依「六、輸出檔案的保管」處理。〔府〕
4. **例外**：使用市府自建或不對外聯網的 AI 環境時，依機關規定，可以依機密等級分級讓 AI 處理真實資料。〔府〕市府 AI 作業指引絕對禁止事項第 1 項

5. **資料留在承辦人的電腦。** 工具在本機處理，不得把資料上傳到線上轉檔網站、雲端試算表或任何外部服務。〔府〕
6. **不修改原始檔案。** 讀取原檔，輸出成新檔；新檔名加上「_整理後」和日期，例如 `報名名單_整理後_1151019.xlsx`、`簡報_更新後_1151019.pptx`。輸出檔已經存在時，另外加編號，不要直接覆蓋；由瀏覽器下載存檔的 HTML 工具，同名檔案交由瀏覽器自動加編號處理，並在交付說明寫明。〔建議〕
7. **畫面與紀錄不顯示個資。** 程式執行時的訊息只顯示筆數與處理結果（「共讀取 1,203 筆，輸出 1,198 筆，5 筆有問題」），不要把姓名、電話印在畫面或紀錄檔裡。〔建議〕

### 二、選擇做法

先問承辦人：「您的電腦能不能自己安裝軟體？」再依下表選擇：

| 情況 | 建議做法 | 說明 |
|---|---|---|
| 不能安裝軟體 | Excel 內建功能（公式、Power Query），或一個在瀏覽器打開的 HTML 工具 | HTML 工具要在本機執行、不連網路；用到的函式庫要放在工具資料夾裡，不連外部網站 |
| 可以安裝 Python，或機關已有 Python 環境 | Python 程式（Excel 用 openpyxl、pandas；Word 用 python-docx；PowerPoint 用 python-pptx；PDF 用 pypdf 等） | 附上簡單的執行方式（Windows 按兩下就能執行的 `.bat` 檔，或明確的一行指令） |
| 只需要在 Word、Excel 裡重複做同一件事 | Office 內建功能（Word 合併列印、樣式、Excel 公式），必要時才用巨集 | 巨集可能被機關資安設定擋下，使用前請承辦人確認機關是否允許 |
| 機關資訊單位有指定工具 | 依機關規定 | |

不論哪一種，都要讓承辦人**不懂程式也能用**：

- 執行方式越簡單越好，例如按兩下執行檔、把檔案拖進視窗，或貼上一行指令。
- 要輸入的設定（例如檔案位置、欄位名稱）放在程式最上方或另一個設定檔，並用中文註解說明。
- 錯誤訊息用白話寫出哪裡有問題、要怎麼處理（「找不到『手機號碼』這一欄，請確認 Excel 第一列的欄位名稱」），不要直接顯示程式錯誤訊息。
- 有畫面或產出文件、簡報時，沒有指定就用預設設計，不自己加漸層背景、emoji 這類裝飾；承辦人指定其他風格時，依 `web-ui.md`「八」的（二）、（三）辦理。產出的文件沿用原檔或機關範本的格式。
- 程式顯示的所有文字（提示、進度、完成訊息、錯誤訊息）都依 `writing.md`：不用 emoji、驚嘆號，也不用「一鍵搞定」「輕鬆完成」「處理完成 🎉」這類 AI 常用的說法。例如完成時寫「已整理完成，共輸出 1,198 筆，檔案存在『輸出』資料夾」。

### 三、Excel 常見陷阱

下列情況要在程式裡處理好，不必請承辦人處理：

- 身分證字號、電話、郵遞區號開頭的 0 消失：一律以文字讀取。
- 日期變成數字（例如 46310）：轉回日期；民國年與西元年要依欄位內容判斷，並在交付說明寫明怎麼判斷。
- 合併儲存格、空白列、多餘的標題列：先處理再計算。
- 全形與半形、前後空白、同一個字的不同寫法（臺／台）：比對前先統一。
- 同一個人重複出現：依承辦人指定的規則判斷（例如「手機號碼相同視為同一人」），不要自己決定。
- 輸出 CSV 要讓 Excel 正確顯示中文：用 UTF-8 加上 BOM 編碼。
- 防止公式被執行：輸出 CSV 時，儲存格開頭是 `=`、`+`、`-`、`@`（以及 Tab、換行）的內容，前面加單引號；輸出 `.xlsx` 時，一律以「文字」型態寫入儲存格，就不會被當成公式，不必再加單引號（加了會顯示在儲存格裡）。

### 四、Word、PowerPoint、PDF 常見陷阱

- **保留原本的格式。** 修改文件時，沿用原檔的樣式、字型、頁首頁尾、頁碼、版面配置，不要另外套用新樣式。公文依機關的公文格式與字型（例如標楷體）辦理，有範本就用範本。
- **舊格式**：`.doc`、`.ppt` 要先請承辦人另存成 `.docx`、`.pptx`，程式不直接處理舊格式。
- **隱藏的資訊會跟著檔案出去。** Word 的追蹤修訂與註解、PowerPoint 的備忘稿與隱藏投影片、檔案內容裡的作者與修改紀錄，可能含有不該對外的內容。產生要對外提供的檔案時，預設移除這些資訊，並在交付說明提醒承辦人確認。
- **套印（合併列印）**：例如依名單產生每人一份證書、通知單。每份檔案的檔名要能辨識（例如加上流水號），但檔名不要放完整個資（例如身分證字號）；產生後顯示總份數，讓承辦人核對和名單筆數一致。
- **表格與圖表**：Word、PowerPoint 裡的表格常有合併儲存格；圖表的資料可能藏在內嵌的 Excel 裡。修改前先確認結構，改完要能正常開啟。
- **PDF**：掃描的 PDF 是圖片，沒有文字可以擷取，需要文字辨識（OCR），辨識結果一定要人工核對。不要把 PDF 上傳到線上轉檔或 OCR 網站。
- **字型**：產生的檔案在其他電腦打開時，字型可能不同而跑版。優先使用 Windows 內建的中文字型；需要特定字型時，在交付說明寫明。

### 五、結果要能核對

承辦人要能確認工具沒有算錯：

- 處理完顯示筆數核對：讀進幾筆、輸出幾筆、排除幾筆、有問題幾筆。
- 有問題或被排除的資料，另外輸出一份清單，寫明原因（例如「第 15 列：手機號碼只有 9 碼」），讓承辦人人工確認。
- 有加總、統計時，在交付說明寫明計算方式，並建議承辦人抽幾筆人工核對。
- 文件類工具（套印、改格式、擷取文字）要請承辦人打開幾份輸出檔，確認版面、字型、內容正確。

### 六、輸出檔案的保管

輸出檔若含個資，交付說明要提醒：

- 存放在機關規定的位置，不要放在桌面、隨身碟或個人雲端硬碟。
- 用完依保存期限刪除，包括中間產生的暫存檔。
- 要寄給別人時，依機關規定加密或使用公務檔案傳輸方式。
