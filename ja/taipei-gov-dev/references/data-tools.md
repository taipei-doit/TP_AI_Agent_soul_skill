# 文書・データ処理ツール

適用範囲：Excel、CSV、Word、PowerPoint、PDF などのファイルを処理するツール。例：名簿の整理、複数ファイルの統合、公文書や証書の一括差込み印刷、スライドや文書からの文字抽出、形式の変換、帳票の作成、ファイル名の一括変更。この種のツールは担当職員のパソコンで動くので、ウェブサイトのレイアウト、ロゴ、フッターの規定は要らない。ブラウザで開く HTML ツールとして作る場合は、画面について別に SKILL.md の B 類に従う。

> 標記の説明：〔法〕法律に明文の規定があるもの。〔府〕行政院または台北市政府の指針・規定。〔推奨〕本規範が推奨するやり方。法令の原文と出典は `legal-sources.md` を参照。

### 一、プログラムを書く前にデータを守る

まず次の二つをはっきり区別する。

| | AI がデータを読む | プログラムがローカルでデータを処理する |
|---|---|---|
| 何か | あなた（AI）がファイルを開く、プレビューする、又はプログラム実行時に出力された内容を見ること | あなたが書いたプログラムを担当職員が自分のパソコンで実行し、実際のファイルを読むこと |
| データの行き先 | AI サービスに送られる | 担当職員のパソコンにとどまる |
| 実際のデータでよいか | 個人情報や未公開の公務情報を含む場合は**不可**（例外は下記） | **可**。まさにこの種のツールの目的である |

つまり、プログラムが実際の Excel や Word を読むのは正常なことで、プログラムではふつうにローカルのファイルを読み込めばよい。してはならないのは、実際のデータの内容を AI に渡すことである。

1. **あなたは実際のファイルの中身を読まない。** 担当職員から渡される Excel には市民の氏名、電話番号、身分証番号がよく含まれる。Word や PowerPoint には起案文書、会議資料、未公開の政策内容がよく含まれる。あなたがこれらの内容を読めば、データを AI サービスに送ったことになり、行政院の生成 AI 参考指針第四点（秘密とすべき情報、個人情報及び公開に同意を得ていない情報を提供してはならない）と市政府指針に反する。〔府〕
   - Excel、CSV：欄の名前（1 行目）と、**架空のデータに置き換えた**サンプル 3〜5 行を担当職員に出してもらう。
   - Word、PowerPoint、PDF：**内容を架空の文字に置き換え**、元のレイアウトと書式は残したサンプルファイルを出してもらうか、レイアウトを文章で説明してもらう（例：「1 ページ目は表題、2 ページ目以降は各ページに表が一つ、表は 4 列」）。
   - たとえば次のように伝える。「市民のデータと公務情報を守るため、本物のファイルは見せないでください。内容を架空のデータに置き換えたサンプルを、書式はそのままで別に保存してください。私はその書式に合わせてプログラムを書きますので、本物のファイルはそのプログラムで処理してください。」
   - 担当職員がすでに本物のファイルをフォルダに置いている場合は、ワークシート名やファイルの概要も含め、開いたりプレビューしたりしない。ファイル名に個人情報が含まれることもあるので、一覧も表示しない。ファイルの数や名前を知る必要があるときは、担当職員に教えてもらい、サンプル版を別に保存してもらう。
   - ファイル名や内容に「密」「機密」の表示がある、又は明らかに機密文書である場合は、soul.md 三（一）に従って作業を止める。機密文書の作成には生成 AI を使ってはならない。〔府〕
2. **実際のデータを処理するプログラムは、担当職員自身が実行する。** あなたは架空のデータでだけ実行・テストする。あなた（AI ツール）がプログラムを実行して実際のファイルを処理すると、プログラムが出力するメッセージやエラーメッセージ内のデータがあなたの目に入り、結局データを AI に送ることになる。納品時には、担当職員が自分で実行する方法をはっきり書く。〔府〕
3. **プログラムが実際のデータを処理するには、三つの条件を満たす。** 担当職員自身の公務用パソコン又は機関が承認した環境で実行する。データをどの外部サービスにもアップロードしない。出力ファイルは「六、出力ファイルの保管」に従って扱う。〔府〕
4. **例外。** 市政府が自ら構築した、又は外部ネットワークに接続しない AI 環境を使う場合は、機関の規定に従い、機密等級に応じて段階的に AI に実際のデータを処理させてよい。〔府〕市政府の AI 作業指針の絶対禁止事項第 1 項

5. **データは担当職員のパソコンにとどめる。** ツールはローカルで処理し、データをオンライン変換サイト、クラウドのスプレッドシートその他の外部サービスにアップロードしてはならない。〔府〕
6. **元のファイルを変更しない。** 元のファイルを読み、新しいファイルに出力する。新しいファイル名には「_整理後」（整理済み）と日付を付ける。例：`報名名單_整理後_1151019.xlsx`、`簡報_更新後_1151019.pptx`。出力ファイルがすでにある場合は番号を付け足し、上書きしない。ブラウザでダウンロード保存する HTML ツールでは、同名ファイルにはブラウザが自動で番号を付けるのに任せ、そのことを納品説明に書く。〔推奨〕
7. **画面と記録に個人情報を表示しない。** プログラム実行時のメッセージには件数と処理結果だけを表示し（「共讀取 1,203 筆，輸出 1,198 筆，5 筆有問題」（1,203 件を読み込み、1,198 件を出力、5 件に問題あり））、氏名や電話番号を画面やログファイルに出力しない。〔推奨〕

### 二、やり方を選ぶ

まず担当職員に「您的電腦能不能自己安裝軟體？」（お使いのパソコンにご自身でソフトをインストールできますか）と尋ね、次の表から選ぶ。

| 状況 | 推奨するやり方 | 説明 |
|---|---|---|
| ソフトをインストールできない | Excel の組込み機能（数式、Power Query）、又はブラウザで開く HTML ツール | HTML ツールはローカルで動かし、ネットワークに接続しない。使うライブラリはツールのフォルダに入れ、外部サイトに接続しない |
| Python をインストールできる、又は機関に Python 環境がある | Python のプログラム（Excel は openpyxl、pandas。Word は python-docx。PowerPoint は python-pptx。PDF は pypdf など） | 簡単な実行方法を添える（Windows でダブルクリックすれば実行できる `.bat` ファイル、又は明確な一行のコマンド） |
| Word や Excel で同じ作業を繰り返すだけ | Office の組込み機能（Word の差込み印刷、スタイル、Excel の数式）。必要なときだけマクロを使う | マクロは機関のセキュリティ設定で止められることがあるので、使う前に機関が認めているかを担当職員に確認してもらう |
| 機関の情報部門が指定するツールがある | 機関の規定に従う | |

どのやり方でも、担当職員が**プログラムをわからなくても使える**ようにする。

- 実行方法はできるだけ簡単にする。例：実行ファイルをダブルクリックする、ファイルを画面にドラッグする、一行のコマンドを貼り付ける。
- 入力する設定（例：ファイルの場所、欄の名前）はプログラムの冒頭か別の設定ファイルに置き、中国語のコメントで説明する。
- エラーメッセージは、どこに問題があり、どうすればよいかを平易に書き（「找不到『手機號碼』這一欄，請確認 Excel 第一列的欄位名稱」（「手機號碼」の欄が見つかりません。Excel の 1 行目の欄名を確認してください））、プログラムのエラーメッセージをそのまま表示しない。
- 画面がある場合や文書・スライドを出力する場合は、指定がなければ既定のデザインを使い、グラデーションの背景や emoji のような装飾を自分で加えない。担当職員が別のスタイルを指定した場合は、`web-ui.md`「八」の（二）、（三）に従う。出力する文書は元のファイル又は機関のテンプレートの書式を引き継ぐ。
- プログラムが表示するすべての文字（案内、進捗、完了メッセージ、エラーメッセージ）は `writing.md` に従う。emoji や感嘆符を使わず、「一鍵搞定」（ワンクリックで完了）「輕鬆完成」（簡単に完了）「處理完成 🎉」（処理完了 🎉）のような AI がよく使う言い方もしない。たとえば完了時は「已整理完成，共輸出 1,198 筆，檔案存在『輸出』資料夾」（整理が完了しました。1,198 件を出力し、ファイルは「輸出」フォルダに保存しました）と書く。

### 三、Excel のよくある落とし穴

次の事項はプログラムの中で処理し、担当職員に処理を求めない。

- 身分証番号、電話番号、郵便番号の先頭の 0 が消える：必ず文字列として読む。
- 日付が数字になる（例：46310）：日付に戻す。民国暦か西暦かは欄の内容から判断し、どう判断したかを納品説明に書く。
- 結合セル、空行、余分な見出し行：先に処理してから計算する。
- 全角と半角、前後の空白、同じ字の異なる書き方（臺／台）：照合の前に統一する。
- 同じ人が重複して現れる：担当職員が指定したルール（例：「携帯電話番号が同じなら同一人物とみなす」）で判断し、自分で決めない。
- CSV を出力して Excel で中国語を正しく表示させる：BOM 付き UTF-8 で書き出す。
- 数式の実行を防ぐ：CSV を出力するときは、`=`、`+`、`-`、`@`（及びタブ、改行）で始まるセルの内容の前に単一引用符を付ける。`.xlsx` を出力するときは、必ず「文字列」型でセルに書き込む。そうすれば数式として扱われないので、単一引用符を付ける必要はない（付けるとセルに表示されてしまう）。

### 四、Word、PowerPoint、PDF のよくある落とし穴

- **元の書式を残す。** 文書を修正するときは、元のファイルのスタイル、フォント、ヘッダー・フッター、ページ番号、レイアウトを引き継ぎ、新しいスタイルを別に当てない。公文書は機関の公文書書式とフォント（例：標楷體（楷書体））に従い、テンプレートがあればテンプレートを使う。
- **古い形式**：`.doc`、`.ppt` は、まず担当職員に `.docx`、`.pptx` で保存し直してもらい、プログラムで古い形式を直接扱わない。
- **隠れた情報もファイルと一緒に外に出る。** Word の変更履歴とコメント、PowerPoint のノートと非表示スライド、ファイル内の作成者や更新履歴には、外に出すべきでない内容が含まれることがある。外部に提供するファイルを作るときは、既定でこれらの情報を削除し、確認するよう納品説明で担当職員に注意を促す。
- **差込み印刷**：例：名簿から一人一通の証書や通知書を作る。各ファイルのファイル名は識別できるようにする（例：連番を付ける）が、ファイル名に完全な個人情報（例：身分証番号）は入れない。作成後に総数を表示し、名簿の件数と一致するかを担当職員が確認できるようにする。
- **表とグラフ**：Word や PowerPoint の表には結合セルがよくある。グラフのデータは埋め込まれた Excel に隠れていることがある。修正前に構造を確かめ、修正後も正常に開けるようにする。
- **PDF**：スキャンした PDF は画像であり、抽出できる文字がないので、文字認識（OCR）が必要である。認識結果は必ず人が確認する。PDF をオンライン変換サイトや OCR サイトにアップロードしない。
- **フォント**：作成したファイルを別のパソコンで開くと、フォントが違ってレイアウトが崩れることがある。Windows に標準で入っている中国語フォントを優先して使い、特定のフォントが必要な場合は納品説明に書く。

### 五、結果を確認できるようにする

ツールが計算を誤っていないことを担当職員が確かめられるようにする。

- 処理後に件数の照合を表示する：読み込んだ件数、出力した件数、除外した件数、問題のある件数。
- 問題のあるデータや除外したデータは、別に一覧を出力して理由を書き（例：「第 15 列：手機號碼只有 9 碼」（15 行目：携帯電話番号が 9 桁しかない））、担当職員が人の目で確認できるようにする。
- 合計や集計がある場合は、計算方法を納品説明に書き、何件かを抜き出して人が確認するよう担当職員に勧める。
- 文書系のツール（差込み印刷、書式変更、文字抽出）では、出力ファイルをいくつか開いて、レイアウト、フォント、内容が正しいかを確認するよう担当職員に求める。

### 六、出力ファイルの保管

出力ファイルに個人情報が含まれる場合は、納品説明で次のことに注意を促す。

- 機関が定める場所に保存し、デスクトップ、USB メモリ、個人のクラウドストレージには置かない。
- 使い終わったら保存期間に従って削除する。途中で作られた一時ファイルも含む。
- ほかの人に送るときは、機関の規定に従って暗号化するか、公務用のファイル転送手段を使う。
