# アクセシビリティ

適用範囲：すべてのウェブ画面。内部小ツールは「三、どの等級でも行うこと」だけを満たせばよい。

> 標記の説明：〔法〕法律に明文の規定があるもの。〔府〕行政院または台北市政府の指針・規定。〔推奨〕本規範が推奨するやり方。法令の原文と出典は `legal-sources.md` を参照。

### 一、法的根拠

〔法〕「身心障礙者權益保障法」（障害者権益保障法）第52条の2は、「各級政府及びその附属機関（構）、学校が構築するウェブサイトは、第一優先等級以上のアクセシビリティ検査に合格し、認証マークを取得しなければならない。」と定めている。検査の基準は、デジタル発展部が公告した「網站無障礙規範」（ウェブサイトアクセシビリティ規範）で、A、AA、AAA の三等級に分かれる。現行版は WCAG 2.1 を参照している。民国115年5月29日に改正された新版は民国115年11月30日に施行され、WCAG 2.2 の達成基準が追加される。例えば、フォーカスが固定ヘッダーなどの要素に隠れてはならない（2.4.11）、クリック対象は十分に大きくなければならない（2.5.8）、ログインを記憶やパズルによる認証だけに頼ってはならない（3.3.8）といったものである。新たに開発するサイトは、最初から新版に沿って設計すること。法定の最低要件は第一優先等級（A）であるが、実務上、新規構築や改修のサイトの多くは AA を目標としており、本規範も AA を最低線とする。

### 二、機能に応じて目標等級を判断する

機能が単純なほど、AAA を達成しやすい。着手前に、AI は下表に従って判断し、その結果を担当職員に伝えて確認を受けなければならない。

| 機能の程度 | 典型例 | 目標等級 |
|---|---|---|
| 単純 | 情報だけのページ、お知らせページ、1〜3 項目の単一フォーム、単一結果の照会 | **AAA** |
| 中程度 | 複数ステップの申請フォーム、照会と一覧とページ送り、絞り込みと並べ替え、ログインが必要な管理画面 | **少なくとも AA**。下に挙げる AAA の項目はできるだけ満たす |
| 複雑 | 地図、インタラクティブなグラフ、リアルタイムに更新されるデータ、動画・音声、ドラッグ操作、第三者サービスの埋め込み | **AA が最低線**。AAA を満たせない項目と代替策を挙げる |

担当職員に伝えるときは、次の言い方を参考にしてよい。

> このウェブページは照会欄が一つと結果表示欄が一つだけで、機能が単純なページに当たるため、AAA を目標とすることを提案します。達成する予定の主な点は、文字のコントラスト比 7:1 以上、操作の制限時間を設けないこと、エラーメッセージで正しい形式を説明することです。後で地図を追加する場合は、改めて評価します。この方針でよろしいでしょうか。

サイトに後から新しい機能（例えば地図）を加えた場合は、改めて判断する。

### 三、どの等級でも行うこと

- `<html lang="zh-Hant-TW">`。
- ページで最初にキーボードで移動できる要素は「跳到主要內容」（メインコンテンツへ移動）のリンクとする。
- 導盲ブロック（アクセスキーの目印）：ヘッダー、メインコンテンツ、フッターの冒頭にそれぞれ `:::` のリンクを一つ置き、`accesskey="U"`（上部）、`"C"`（中央）、`"Z"`（下部）を設定する。通常は非表示にし、キーボードで移動したときだけ表示する。
- `<header>`、`<nav>`、`<main>`、`<footer>` で領域を示す。`<footer>` は `<main>` の中に置かない。
- 各ページの `<h1>` は一つだけとし、見出しの階層を飛ばさない（h1 の下は h2 とし、いきなり h3 にしない）。
- 意味のある画像には `alt` を書き、純粋な装飾画像には `alt=""` と書く。
- すべての入力欄に対応する `<label>` を付ける。
- すべての機能をキーボードだけで操作でき、現在のフォーカスの位置が見えるようにする（フォーカス枠：主色の 3px の外枠、`outline-offset: 2px`）。ボタン、リンク、入力欄など操作できる要素で、`outline: none` によってフォーカス枠を消してはならない。唯一の例外は `tabindex="-1"` のジャンプ先（例えば `<main>`）で、「跳到主要內容」の移動先として置くだけで利用者が操作するものではないため、フォーカス枠を表示しなくてよい。
- 色だけで情報を伝えてはならない。
- 動的に表示される結果は `role="status"` の領域に置く。

自分または課内だけで使う小ツール（SKILL.md の B 類）は、導盲ブロックとフッター（`<footer>`）を省略してよい。ページが短い場合は「跳到主要內容」も省略してよい。その他の項目はすべて満たす。

### 四、AAA で追加して行うこと

AAA を目標とするページは、上記の基本項目に加えて次を満たす。

- 通常の文字のコントラスト比は 7:1 以上、大きな文字（24px 以上、または 18.66px 以上の太字）は 4.5:1 以上。
- 一行は 40em 以下、行間は 1.5 以上、段落間隔は行間の 1.5 倍以上とし、両端揃えにしない。
- 文字を 200% に拡大しても横スクロールバーが出ない。
- 画像で文字を表示しない（ロゴを除く）。
- 操作の制限時間を設けず、自動更新せず、自動でスライドを切り替えない。
- 点滅するコンテンツがない。
- パンくずリストがあり、利用者が現在地をわかるようにする。
- リンクの文言だけで行き先がわかるようにし、「點此」（ここをクリック）、「更多」（もっと見る）を使わない。
- 見出しで内容を区切る。
- クリックできる箇所は 44×44px 以上とする。
- 専門用語や略語は少なくし、どうしても使う場合は初出で説明する。文章は中学生が読んでわかる程度にする。
- 入力欄の横に例と説明を示す。
- 送信前に確認・修正ができ、送信後に取消しや訂正ができる。

### 五、AAA を満たせない場合の代替策

| 機能 | 達成が難しい項目 | 代替のやり方 |
|---|---|---|
| 動画 | 手話通訳、拡張音声解説 | 少なくとも字幕と文字起こしを提供する |
| 地図 | マウスでしか選択できない | 住所や行政区を文字で照会できる手段を別に用意し、結果も一覧で示す |
| グラフ | 図が見えない人には理解できない | グラフの下に同じデータの表を示す |
| リアルタイム更新 | 内容が勝手に動く | 「更新を一時停止」を設けるか、ボタンによる手動更新に変える |
| ログインのタイムアウト | タイムアウトを設けない | タイムアウト前に知らせ、ボタンを一度押せば延長できるようにする |
| 法令の条文 | 読解の難度が高すぎる | 条文の横に平易な要約を添える |

### 六、アクセシビリティ認証マークと宣言

- どのサイトにも「無障礙聲明」（アクセシビリティ宣言）のページを設け、適用範囲、アクセスキー（U／C／Z）、キーボードの操作方法、連絡先を説明する。
- アクセシビリティ認証マークは、機関がデジタル発展部に申請する。まず Freego 検査ツールで自己検査を行い、次にオンラインで登録・申請し、人による検査に合格すると交付される。有効期間は 3 年である。申請者は機関でなければならず、受託事業者が代理で申請することはできない。
- **サイトが認証マークを取得する前に、マークの画像を置いてはならない。** 取得後は交付時の仕様どおりに置き（画像サイズは変更不可）、デジタル発展部の認証マーク情報ページにリンクし、`alt` には等級を明記する。例：「通過AAA無障礙網頁檢測」（AAA アクセシビリティ検査合格）。
- AI が機関に代わって検査に合格したと宣言してはならない。言えるのは「○○ 等級に沿って設計しており、Freego による検査を受けることを推奨する」ということだけである。
