# 情報セキュリティ

適用範囲：すべてのプログラム。

> 標記の説明：〔法〕法律に明文の規定があるもの。〔府〕行政院または台北市政府の指針・規定。〔推奨〕本規範が推奨するやり方。法令の原文と出典は `legal-sources.md` を参照。

### 一、以下はあなたの責任で行い、担当職員に尋ねなくてよい

担当職員は攻撃手法の名前を知る必要はなく、防ぐかどうかを担当職員に決めさせるべきでもない。次のやり方を既定とし、プログラムを書くときにそのまま実施する。〔推奨〕

| 防ぐこと | 平易な説明（担当職員に説明が必要なときに使う） | あなたがすること |
|---|---|---|
| SQL インジェクション | 誰かが入力欄に特殊な文字を入れ、データベースのデータを盗み見たり消したりする | パラメータ化クエリまたは ORM |
| XSS（クロスサイトスクリプティング） | 誰かが入力欄にプログラムを入れ、そのページを見た他の人のアカウントが乗っ取られる | 出力時にエスケープする。フロントエンドでは `textContent` を使い、テンプレートエンジンは自動エスケープを有効にする |
| CSRF（クロスサイトリクエストフォージェリ） | 別のサイトが、ログイン中のあなたの身分を勝手に使ってデータを送信する | フォームに CSRF トークンを付け、Cookie に `SameSite` を設定する |
| 権限の回避 | URL を知っていれば見てはいけないデータが見られる | すべてのバックエンド機能で身元と権限を検査する |
| パスワードの漏えい | データベースが盗まれたときにパスワードがそのまま露出する | パスワードはハッシュ化して保存する（`systems.md` 三を参照） |
| 秘密情報をプログラムに書く | ソースコードが流出するとパスワードや鍵も一緒に流出する | 環境変数または設定ファイルを使い、バージョン管理に入れない |
| ファイルアップロード攻撃 | 偽装したプログラムファイルをアップロードし、サーバー上で実行する | `systems.md` 四に従う |
| スプレッドシートの数式インジェクション | エクスポートしたファイルを Excel で開くと数式が自動で実行される | CSV：セルの先頭が `=`、`+`、`-`、`@` の場合は単一引用符を付ける。`.xlsx`：文字列型で書き込む |
| 出所不明のパッケージ | バックドアのある製品や国家の情報通信セキュリティを害する製品を使ってしまう | `tech-stack.md` 五に従う。〔法〕「資通安全管理法」（情報通信セキュリティ管理法）第11条 |

実施後は `verification.md` に従ってテストし、ありのままに報告する。担当職員に説明するときは、左の列の専門用語ではなく、中央の列の平易な説明を使う。

### 二、プログラムの書き方

- 画面に個人情報を表示する場合は既定でマスクする。例：「王○明」「A12****789」「0912-***-678」。〔推奨〕
- 個人情報をフロントエンドのプログラム、ブラウザの localStorage、URL パラメータ、ログファイルに書き込んではならない。〔推奨〕
- テストデータには常に架空のデータ（「王小明」「0912-345-678」）を使い、実在の市民のデータを使ってはならない。〔府〕
- パスワード、鍵、データベース接続文字列をソースコードに書いてはならない。環境変数を使い、`.env` を `.gitignore` に加える。
- 利用者が入力した内容は常に信頼できないものとして扱う。
  - 画面に表示するときは `textContent` を使い、`innerHTML` で連結してはならない。
  - データベースの照会にはパラメータ化クエリを使い、文字列連結で SQL を組み立ててはならない。
  - フロントエンドとバックエンドの両方で形式を検査する。
- エラーページにプログラムのエラー詳細（スタックトレース、データベースのメッセージ）を表示してはならない。
- トラッキング用の Cookie は使わない。Cookie が必要な場合は `Secure`、`HttpOnly`、`SameSite=Lax` を設定する。

### 三、本番環境の設定

本番サーバーにデプロイするときは、次の HTTP ヘッダーを設定する（機関の情報部門またはサーバー管理者に設定を手伝ってもらう。納品説明で注意を促すこと）。

```
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'; img-src 'self' data:; style-src 'self'; script-src 'self'; frame-ancestors 'none'; base-uri 'self'; form-action 'self'
X-Content-Type-Options: nosniff
X-Frame-Options: DENY
Referrer-Policy: strict-origin-when-cross-origin
```

上記の CSP を適用できるよう、プログラムにインラインの `<script>` や `style="..."` を書かず、すべて独立した `.js`、`.css` ファイルに置く。

その他の注意事項は次のとおり。

- サイト全体で HTTPS を使う。
- 外部に公開するシステムは、本番稼働前に脆弱性スキャンを行う。機関の情報通信セキュリティ責任等級によっては、ペネトレーションテストも必要になる場合がある。担当職員から機関の情報部門に相談してもらう。〔府〕システム開発と外部委託は「臺北市政府資通安全管理規定」（台北市政府情報通信セキュリティ管理規定）に従う。
- 管理画面があるものは、ログインと権限管理を必ず設け、「URL を公開していない」ことだけに頼ってはならない。
- 必要なアクセス記録（日時、送信元 IP、操作）を保存し、保存期間を明記する。
